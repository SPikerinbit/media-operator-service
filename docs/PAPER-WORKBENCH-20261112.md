# 投稿与笔记工作台：纸张、固定布局及放映区

2026-11-12；版本保持 0.5.0。已完成构建、静默覆盖安装和启动。

## 实现

- 每次执行持久化独立身份及剩余工作计划。队列与 SSE 兼容扩展 `execution_id`、`work_progress`、`work_progress_known`、`waiting_for_shared`，保留旧 `progress`。
- 启动前验证缓存与检查点，排除已确认复用的步骤；运行中共享等待、缓存命中和跳过冻结已确认进度，再分配剩余份额。进度不倒退，成功前最多 99%。笔记摘录增加实际进度记录，直接字幕导入沿用相同执行口径。
- 投稿固定为来信、处理台、内容三分区。列表、表单及记录各自滚动；窗口和详情容器不滚动。处理台各状态共用场景，切任务只更新局部内容，保留跨页面导航转场。
- 所有工作区尺寸和断点集中在 `workspaceLayout.css`；清理旧的详情整体滚动规则。小窗口将来信改成抽屉，火盆和主要操作保持可达。
- 飞行纸、处理纸和碎纸共用确定性纸面与场景坐标。纸张按实际进度平移经过火边或刀口，不按时间自动消耗，不纵向压缩纸面。灰屑和纸条按新增消耗量产生。
- 入场约 780ms，目标使用任务及执行身份对应的场景句柄；接管先画处理纸，再移除飞行纸。快速完成直接收尾，避免完整纸重新出现。
- 放映区合并为空间内的一台屏幕，画面预览与成片共用机身；固定 16:9 展示窗口包含源画幅，限制机身最大宽高，加入细小指示灯、音栅和旋钮材质。成片卡片在屏幕下方，切离预览暂停视频。
- 保留投递、折纸、封蜡、木块入盆、火焰暖光、烟雾、拨杆、碎纸定位、三档整理、编辑保存、删除投桶和撤销。修正删除收尾期间撤销按钮状态与动作忙碌状态不一致的问题。
