# Media Operator 0.5 最终验收计划

本文是 0.5 版本（`dev` 分支，含拟物前端 PR #5）的验收清单。每一项写明**怎么测**和**通过标准**，验收人逐项打勾，并在「结果」栏填写 通过 / 部分通过 / 不通过 及备注。

- 验收分支：`dev`（合并提交 `efadcea` 及之后）
- 目标平台：Windows 10/11 x64；建议同时在带 NVIDIA 显卡和纯 CPU 的机器上各跑一遍
- 显示环境：1280×800、1920×1080 两种窗口尺寸，系统缩放 100% 与 150%
- 录屏要求：动效类条目需录屏（≥ 60fps），并用逐帧方式复核；截图只能证明静态状态

## 6. 视觉与动效验收

总体基调：早期 Apple（iOS 6 / Mountain Lion）拟物风格**只用在物件上**；背景是纯色浅蓝灰，不加纹理、不用木纹；全局统一左上方单一光源，阴影柔和、有贴地接触阴影，无硬边、色带或底板痕迹；动效柔和有弹性、落地有轻微回弹；所有出现和消失都有入场 / 离场动画，切页用抽屉、翻页、推拉之类的物理隐喻。

每条需录屏并逐帧确认，「通过」须有对应帧截图作证。

## 7. 截至 2026-11-11 的已知未完成项

以下为最后一轮复核时仍存在的问题，验收时重点确认：

1. 碎纸机正面被三档选项面板整块覆盖，看不出碎纸机本体（对应 6.3.1、6.3.2）。
2. 纸屑托盘比机身宽，左侧被页面边缘裁掉；纸屑偏大且排成一行（6.3.4、6.3.5）。
3. 连线从机身侧面伸出，而不是从托盘引出（6.3.6）。
4. 投稿准备页木块悬空并压住「字幕样式」文字；火盆暖光脱离火盆漂浮在下方（6.2.3、6.2.6）。
5. 处理阶段火盆看似空盆，火苗与暖光不明显（6.2.5）。
6. 飞向火盆的稿纸刚起飞时压住左侧列表文字（6.2.7）。
7. 设置页账号图标为空白色块，小红书一行底色不一致，右侧留白过多（6.4.1、6.4.3）。
8. 引导卡入场时站点列表晚一拍出现；离场时半透明叠在首页上（6.5.1、6.5.3）。
9. 首页偶见一道残留细线（6.1.8）。
10. 微信读书长文本提取已用解析测试覆盖，尚未用真实已登录账号验证（5.4）。
