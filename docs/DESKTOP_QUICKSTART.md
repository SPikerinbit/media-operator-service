# Media Operator Windows 试用说明

在 Windows 11 x64 上运行 MediaOperatorSetup.exe，在安装位置页面选择目录。有 D 盘时，新安装默认选中 `D:\Media Operator`。然后从桌面打开 Media Operator。安装包未签名。若系统缺少 WebView2，安装程序会联网补齐。

首次使用时，在「设置 → 转录与本地资源」点击「检测本地环境」，并下载计划使用的 Whisper 模型。下载完成后可离线转录。缺少模型时，任务会在处理素材前提示。FFmpeg、ffprobe、yt-dlp 或 Deno 检测失败时，可重新运行安装程序修复。

## 素材处理

添加本地音视频，或粘贴一条或多条链接及分享文案。队列逐项识别标题、站点、类型和时长。小宇宙可直接导入单集链接。无法解析的项目可单独重试、更换链接，或按提示选择本站的 Netscape Cookie 文件。

视频卡的终点滑条有「导入」「字幕」「翻译」「成片」「投稿」五档。新视频继承「本批默认终点」，初始值为投稿。可单独调整，或勾选视频后批量调整。音频在原文字幕入库后完成，可播放、按时间戳跳转或导出 SRT。只提供合流的在线视频需允许下载后提取音轨。

点击「开始处理」后，应用检查本批依赖。可以先启动就绪项。包含投稿时，确认窗口会列出成片后将自动提交 B 站审核的视频。到「历史任务」查看各项进度或从失败阶段重试。已生成字幕的历史视频可选择「继续到成片」，复用字幕并补齐视频。批次记录采用「日期 时间 · 数量」。

「处理参数」根据所选素材的终点显示相关分类。批次并发数在「批次默认 → 输出 → 批次执行」设置。参数内容可独立滚动，窄窗口通过抽屉打开。

在「批次默认」里，可在「输出」和「样式」分别点击「设为默认」。保存的默认值在下次启动时自动应用。「重置输出」或「重置字幕样式」只恢复对应一组。当前素材也可单独重置，或点击「恢复继承」跟随批次参数。

在「输出 → 推理模式」可选择「严格 GPU · 仅本地模型」。该模式重新转录，CUDA 不可用时会停止任务。字幕字体可选随包提供的思源黑体和思源宋体，也可输入系统已安装的字体名称。

Whisper 可选 `large-v3-turbo`。在「设置 → 转录与本地资源」下载约 1.62 GB 的模型后，可在「输出 → Whisper 模型」中选择并离线转录。

「输出 → 烧录编码」可选择自动、NVIDIA NVENC 或 CPU。自动优先使用 NVIDIA，编码不可用时回退到 CPU。NVENC 只加速视频编码，字幕文字仍由 libass 绘制。任务详情显示实际使用的编码器。

批量投稿默认逐条使用 YouTube 或 B 站的来源封面。本地视频优先使用内嵌封面，取不到封面时使用视频画面。可为当前素材单独选帧或上传封面。

「投稿」默认启用 DeepSeek 填写空白字段。每条视频使用原标题、原简介与字幕节选。标题保留原意并中文化，简介列出主要内容。手动输入优先，自动分区无有效结果时会暂停该条投稿。任务详情可查看生成的投稿信息。

在「任务记录」选择历史批次后，点击「批量投稿到 B 站」并勾选成片。投稿失败的任务默认沿用原投稿参数，也可选择改用当前批次投稿参数。首次投稿使用当前批次默认参数。确认前请核对 B 站创作中心的稿件状态。已有成功投稿记录或成片已移走的任务会标注原因。

在线素材的预览和下载会读取 Windows 系统代理。遇到连接错误时可在应用中重试，详细信息保存在本地任务记录或预览日志中。

## 字幕分析与 Obsidian

1. 在 Obsidian 打开或创建一个 Vault。到 Media Operator 的设置中选择该 Vault 的根目录，保存设置。
2. 导入视频、音频、SRT 或 VTT，也可以从视频任务打开已有字幕。
3. 在「提取观点」旁选择「精选关键句」或「较完整摘录」。点击时间戳回到原话。展开卡片即可编辑译句、主题和说明，自动保存完成后可发布。
4. 点击「发布到 Obsidian」。每张卡生成一篇观点笔记，并链接到共享素材页。发布成功并核对写入结果后，对应的本地草稿会清理。发布失败的草稿可重试。
5. 在 Obsidian 继续编辑、移动和添加双链。应用遇到重复发布会显示原笔记，另存新版本会创建独立文件。

## 资料与构建

资料目录在设置中单独选择。输入 DeepSeek 密钥后，点击该区域的「保存 DeepSeek 设置」。密钥与投稿凭据由 Windows 凭据管理器保存。

在「转录加速」选择 NVIDIA 运行库的安装目录，可选 D 盘文件夹。首次安装下载约 1.2 GB。启用后，自动转录模式优先用 GPU 批量处理，GPU 运行失败会自动重试 CPU。报告问题时可从设置导出脱敏诊断。

从源码构建需要 Windows x64 的 Python 3.12、Node.js 24 和 Inno Setup 7。安装 requirements-desktop.txt 后，运行 scripts/build_desktop.ps1，并传入构建目录、输出目录、ISCC.exe 和 Python 解释器的路径。构建脚本会安装锁定的前端依赖，将生成的静态资源打入安装包。
