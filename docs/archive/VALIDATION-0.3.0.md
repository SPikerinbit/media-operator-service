## 视觉与性能检查

本次采用灰白与炭黑两套配色，蓝色用于操作和选中状态。正文使用本机字体。工具栏、素材列表、原文和观点列表有各自的高度边界，玻璃与循环装饰动画未进入工作内容区域。

指定设计技能的截图和性能脚本已运行。最终性能检查在桌面和窄窗口均为 0 个 FAIL，累计布局位移为 0，无失败资源请求。两项 WARN 均为同一前端脚本约 461 KiB 的解析体积，分别出现在两种检查宽度。

通用网站 Gate 返回上方的 FAIL，未认定整套网站检查通过。其要求包含全屏营销首屏、每节一屏、装饰画面、统一页面内容边线与单一主行动。这些规则与本次固定高度、多栏编辑工作台的需求冲突。列表内部缩进、多个功能按钮和被滚动容器裁剪的字幕，也会被该检查器按宣传页面规则标记。

检查器对两个搜索框提出可见标签要求。搜索框已有图标、用途文字和辅助技术名称，界面采用桌面搜索框的呈现方式。该差异予以记录。

布局检查脚本在当前应用结构下抛出 `TypeError: r.sections is not iterable`，未修改检查器。七种尺寸的边界、滚动、溢出、抽屉及焦点由应用交互测试另行验证。没有通过隐藏内容或修改检测逻辑消除检查结果。

## 兼容与操作说明

- 设置保留原来的配置位置和 Windows 凭据管理器。安装包包含程序、工具和许可证，个人配置、凭据与测试资料独立存放。
- 首次升级旧知识库时生成 `knowledge.before-0.3.0.sqlite3`。旧卡片的中文译句默认为空，原有 ID、编辑内容和发布标识继续使用。
- 投稿沿用人工填写优先规则。旧任务缺失原简介时尝试补取，读取失败会提示按现有资料生成。已保存的投稿结果在重试时继续复用。
- 未发布的已保存摘录继续留在本地数据库。生成失败保留已有摘录，发布成功仅清理与写入快照一致的草稿。
- “精选关键句”与“较完整摘录”的条目数是软目标。短片或内容密度低的材料可以少于目标，时间戳与原话由本地字幕提供。

## 可复现检查

后端测试运行 `python -m pytest -q`。前端运行 `npm run build`。

界面压力服务由 `tests/ui_server.py` 接受独立测试目录，在 `127.0.0.1:8799` 启动。安装 Playwright 后运行 `tests/ui_interaction.cjs`，并传入结果目录。测试只面向该服务的固定测试会话，测试代码中的凭据均为模拟值。

交付附件包含安装 EXE、SHA-256 文件、使用说明，以及视频制作、字幕分析、最小窗口与设置页截图。上一版本安装包保存在 D 盘历史版本目录。
