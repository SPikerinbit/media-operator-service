# Desktop interface references

The desktop interface includes the following vendored source. The associated MIT licenses are in src/vendor and included in the Windows installer.

- BoardUI Button and Chip, from BoardUI/boardui at ec5c5eb3e29c2441be63b9422cd54f411ef23466. Imports and theme variables are adapted to the desktop application.
- beUI Animated Collapsible, from starc007/ui-components at fb52f599d1550f006afe0344022cc45a913adab1. Motion constants and reduced-motion opacity are adapted.

The interaction and layout references are BoardUI, Bencho, HeroUI Pro, beUI Pro, Libraries.dev, Watermelon UI, and Apple Human Interface Guidelines.
